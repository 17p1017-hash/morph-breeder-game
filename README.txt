モルフブリーダー Ver.11（複合モルフ画像図鑑30種）

・index.html / styles.css / data.js / morphs.js / combo_photos.js / game.js と assets/ をすべてGitHubに置いてください。
・写真16枚は従来のまま同梱。新たな30複合モルフは登録候補リストで、写真は未収録です。
・複合モルフ写真を追加するには assets/combos/ に画像を置き、combo_photos.js の image: "" をパスに変更します。
・劣性のクラウン/パイド/デザートゴースト等は2コピーで表現する遺伝子構成として登録。
・登録済み画像は遺伝子・コピー数が一致する場合だけ完全一致として表示。登録がなければ別のモルフの参考写真と明記します。
・画像の利用許諾を確認してください。Webで見つかるだけでは再配布の許可になりません。
・ブラウザ内の既存セーブキー morph-breeder-v1 は維持。更新前のバックアップを推奨します。
・画像ファイル名と一覧表は docs/combo_photo_register.csv でも管理できます。
